# Coding challenge 1

Implementation of challenges 3, 4, and 17 in Python.

## Requirements

- Python 3.8+
- pycryptodome

## Setup

```bash
pip install pycryptodome
```

## Running

```bash
python3 challenge3.py
python3 challenge4.py
python3 challenge17.py
```

## Expected Output

**Challenge 3:**
```
Key: 'X', Plaintext: Cooking MC's like a pound of bacon
```

**Challenge 4:**
```
Line 171, Key: '5', Plaintext: Now that the party is jumping
```

**Challenge 17:** (Example, as plaintext varies randomly)
```
Decrypted: 000003Cooking MC's like a pound of bacon
```
